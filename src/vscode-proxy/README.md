# vscode-proxy

Local stdio MCP proxy, published as the npm package `@aidevme/image-studio-mcp`. Authenticates with the developer's Azure sign-in, forwards calls to the facade through APIM, and downloads returned images into the workspace (architecture component C17).

Status: not implemented yet. See the [implementation plan](../../docs/aidevme-foundry-image-studio/IMPLEMENTATION.md) (Phase 1, P1.11).
