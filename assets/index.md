## Adding an asset

1. Save the file in this folder with a lowercase, hyphen-separated name, such as `architecture-diagram.png`.
2. Add a row for the file to the table in [Files](#files).
3. Reference the file with a relative path from the document that uses it.
4. Update the version and the last-updated date of this document.

> **Note:** GitHub recommends a social preview image of 1280 × 640 px and a file size below 1 MB. The current image is 1197 × 598 px, which has the same 2:1 ratio.
